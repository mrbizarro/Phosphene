# Phosphene 5.0.73

New in Pro:
- iPhone Remote, Pro: a new Before you go out card on the Remote Control page. Before you leave the house it shows in one place whether Remote is on, which iPhone is paired and when it was last seen, and whether this Mac can be reached away from home. It also reminds you to keep the Mac awake or turn on "Wake for network access", because a sleeping Mac cannot answer.

New for everyone (Free):
- Tool titles and labels for Claude and Codex, Free: each Phosphene agent tool now has a plain title (for example "Make a video clip") and says whether it only reads or can change things, so Claude, Codex and agent directories can show it. "Stop the current render" and "Copy finished files to a folder" (which replaces a file with the same name) are marked as ones that can undo or replace something; no tool deletes your files.

Mac app: it picks up this update by itself the next time it starts. Pinokio: press Update, then restart.
