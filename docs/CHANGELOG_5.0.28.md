# Phosphene 5.0.28

Free for everyone:
- P-H3-Image now says when it ignores your reference picture. P-H3-Image makes pictures from words only, so a picture left in the reference slots was dropped without a word and the result looked nothing like it. Now the Images screen shows a heads-up as soon as a reference is loaded with P-H3-Image chosen, and points to MiniMax-H3-Image, which can edit and reuse a picture. You can still generate; nothing is blocked. From a support ticket.

The new text is in the ten languages.

Mac app: no new app to download; the app picks up Studio 5.0.28 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
