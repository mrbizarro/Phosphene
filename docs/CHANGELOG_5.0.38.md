# Phosphene 5.0.38

Fix, free for everyone:
- When macOS's graphics driver stops a render (the "helper exited from SIGABRT" crash), the message now says what happened and what to try: Phosphene already retried it, so go for a shorter clip or a smaller size, quit other apps that use graphics (browser video, games, other AI apps) and keep macOS up to date. It no longer sends you to a GitHub link that does not open.

Mac app: no new app to download; the app picks up Studio 5.0.38 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
