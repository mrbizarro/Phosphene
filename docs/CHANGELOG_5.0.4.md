# Phosphene 5.0.4

**Updates that arrive, a Studio that checks them for you, and a message line from us to you.** Nothing that was free was taken away.

## Mac app

- **Updates survive a bad connection.** A slow or dropping route no longer loses the download: Phosphene carries on where it stopped, retries by itself, and if it truly cannot finish it says so and offers **Try again**. It never just disappears.
- **Updates are found within 10 minutes** and at every launch.
- **"Check for updates" in the Studio works.** The button and the version label in the Studio header start the app's own updater.
- **Your Pro licence stays put.** If an older licence record was left in the Keychain, Phosphene now uses the one you activated last and removes the stale one.
- **A much smaller download.** The app is about 11 MB instead of 80 MB: the video tools are slimmer, and the Python manager is fetched once during first-run setup.
- **A short message from us, once.** A signed notice can reach every copy of Phosphene (a macOS notification and a banner with Update now). Only messages signed by us are ever shown.
- Setup list: songs from 16 GB; training a character (lighter settings) from 24 GB.

## Studio

- **Make your first clip** shows only to people who have never rendered, with three new starter scenes: a fog whale in an empty city, a piano on a frozen lake, the lighthouse keeper and the moon.
- **Remote Control in the left bar:** Free users see a quiet outlined "Pro" beside the name, with the tooltip "Remote Control is part of Pro". Pro users see nothing.
- Links to phosphene.video from the Studio carry anonymous tags that show which page or button brought a visit.
- Pinokio: the same signed messages appear as a banner in the Studio.
