# Phosphene 5.0.7

**H3 now runs from 16 GB.** It used to need 36 GB. It is Free for everyone, with nothing taken away from anyone.

## Free

- **Hailuo H3 on 16 GB and 18 GB Macs.** The model is now read from your drive one block at a time, instead of being held in memory all at once. A Standard 5 s clip used 7.7 GB of working memory in our test, down from 26.9 GB, and the clip came out the same, frame for frame and sound for sound.
- **What a small Mac makes.** From 16 GB: Draft and Standard clips. From 18 GB: High too. If a clip needs more memory than your Mac has, Phosphene says so in plain words before it starts. Clean up sound and the long chained clips still need 36 GB.
- **How we tested.** On a 64 GB Mac limited to the memory of a 16, 18 and 24 GB one. We have not run it on a real 16 GB Mac yet. Smaller chips are slower than the M4 Max we measured on, so expect a longer wait there.
- **The Install button.** The memory check in Pinokio's Install Hailuo H3 now lets a 16 GB Mac through.

## Everywhere

- Press **Update**, then restart (Pinokio). H3's engine files are replaced, your downloaded model files stay.

## Pro

- Nothing changed.
