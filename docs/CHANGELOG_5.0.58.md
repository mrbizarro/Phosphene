# Phosphene 5.0.58

Fixes, for everyone:
- Extend now works on phone clips and videos of an unusual size (like 360×640): it trims a few pixels off the edge instead of stopping with an error.
- Pictures asked for by a script or an AI assistant that names a model family (like flux2_edit) are now made with the picture model you chose in Settings, instead of failing.

Pinokio: press Update, then restart. Mac app: you get it on your next start.
