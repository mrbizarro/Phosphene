# Phosphene 4.19.13

- Fixed a cause of jumps between One Shot sections. Each section now starts from the last picture of the previous one, including when resuming a stopped take.
- Ingredients now checks model compatibility before preparing a render, with instructions for choosing a supported mode.
- Image crashes give more accurate recovery advice, without assuming every crash means insufficient memory.
- Failed model licence saves can be retried, and the app and installer agree on whether acceptance was saved.
- Fixed engine repair failures when the installation path contains spaces.

In Pinokio, press Update, then restart Phosphene. No new models or features are included.
