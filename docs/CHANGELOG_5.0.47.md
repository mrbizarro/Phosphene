# Phosphene 5.0.47

Fixes, for everyone:
- Pinokio: pressing Update when you already have the newest version now tells you that you are up to date, instead of saying the update did not finish. That message also blocked your next update; it no longer does.

Mac app: you get it on your next start. Pinokio: press Update to get it. If Update already stops with "Update did not finish" every time, reinstall Phosphene in Pinokio once to get this fix.
