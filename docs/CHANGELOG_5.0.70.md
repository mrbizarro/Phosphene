# Phosphene 5.0.70

Fixes:
- FLUX 3: on M1 Max and M2 Max Macs, a picture could stop halfway with an error. It now finishes. If one stopped for you, make it again.
- Hailuo H3 on 16 GB Macs: 15 s clips ran out of memory on most of these Macs. A 16 GB Mac now makes Hailuo H3 clips up to 10 s, and the 15 s choice is greyed with the reason. Macs with more memory still make 15 s.

Mac app: it picks up this update by itself the next time it starts. Pinokio: press Update, then restart.
