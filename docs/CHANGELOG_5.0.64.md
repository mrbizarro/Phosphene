# Phosphene 5.0.64

Fixes:
- Pictures: if a batch of pictures stops before the end, the pictures that did finish are now kept in your gallery, and the queue says so. Try again with one picture at a time for the rest.
- Pictures: if picture making stops responding for 30 minutes, Phosphene now says what to do: press Generate again (a download that was running picks up where it left off), and restart Phosphene if it happens again.
- Add sound: if the file you pick has no picture (a sound-only file), Phosphene now says so before it starts and asks for a video clip, instead of failing partway.
- When training a LoRA stops, Phosphene now records a clearer reason, so we can fix the common causes sooner.

Mac app: no new app to download; the app picks up Studio 5.0.64 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
