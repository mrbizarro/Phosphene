# Phosphene 5.0.74

Fixes:
- Training: when a run stops because a file is missing, the card now names the file and says what to do: click Download all in the Train tab, or add your photos again.
- One Shot: pressing Resume on a stopped One Shot whose earlier part was deleted now stops at once and names the missing part, instead of making the rest of the video and failing at the end.

Mac app: it picks up this update by itself the next time it starts. Pinokio: press Update, then restart.
