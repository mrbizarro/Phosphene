# Phosphene 5.0.89

New for everyone (Free, preview):
- **Ming-Image 0.2 Design (Free, preview):** make posters, web UI mockups, sharp on-image text, single-picture edits, and native transparent-background RGBA PNG cutouts locally on Apple Silicon (MIT licence).
- **Sizes and Macs:** Standard (1 MP, about 70 s text-to-image and 2 min edit on M4 Max 64 GB) fits 16 GB Macs and up using disk layer streaming (4.96 GiB T2I / 5.11 GiB edit footprint held to a 16 GB budget on a 64 GB Mac; not yet timed on a real 16 GB Mac); High (4 MP, about 5 min text-to-image on M4 Max 64 GB) fits 24 GB Macs and up.
- **Local Design layout helper:** click **Design layout** under the prompt in Images to turn a short idea into a structured layout prompt locally with Gemma 3.
- **One-time download:** click the download chip next to **Version** in Images to fetch about 33.9 GB directly from Hugging Face (checked by SHA-256, with automatic China mirror fallback).

All new UI strings and What's new lines are translated into all ten Studio languages.

Mac app: it picks up this update by itself the next time it starts. Pinokio: press Update, then restart.
