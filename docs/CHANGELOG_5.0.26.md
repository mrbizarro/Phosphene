# Phosphene 5.0.26

Free for everyone:
- Storyboard: in Grid view, a shot with a problem now shows it. Before, "Render all drafts" could be greyed out with the hint "Fix the problems above first" while nothing on screen pointed at a problem, because only the List view marked the shots. Now the shot's tile goes red with a "!" and names the problem on hover, and the button's hint and the line next to it name every problem ("Fix 2 problems first: Shot 3 has no prompt. Write what happens in it. · Shot 7 is a Character shot with nobody cast."). Reported by a Pro user from a screenshot.

Mac app: no new app to download; the app picks up Studio 5.0.26 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
