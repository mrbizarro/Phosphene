# Phosphene 5.0.46

Fixes, for everyone:
- Pressing Compose while the music maker is still downloading now shows how far the download has got, instead of an error.
- When a song or an Ingredients clip cannot start because something is missing (a second picture, enough memory, the music download), it no longer counts as a crash in our error reports, so real crashes stand out and get fixed sooner.

Mac app: you get it on your next start. Pinokio: press Update to get it.
