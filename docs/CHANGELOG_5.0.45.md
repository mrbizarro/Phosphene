# Phosphene 5.0.45

Fixes, for everyone:
- When a render, an update or a repair stops, the message now says what happened and what to press next, in your language. The technical text is still under Details for troubleshooting.
- Downloads now come from GitHub and Hugging Face first. Our own server only steps in when those are down, so your downloads keep going either way.
- Mac app: setting up on a new Mac also downloads from GitHub and Hugging Face first, with our own server as the backup.

Mac app: you get it on your next start. Pinokio: press Update to get it.
