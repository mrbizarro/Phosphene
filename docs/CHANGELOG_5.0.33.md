# Phosphene 5.0.33

New in Pro:
- Fast draft in half the time. With Pro, LTX-2.5 Balanced clips come out in about half the time on any Mac with 16 GB or more: 76 s instead of 150 s for a 5-second clip on a 64 GB Mac, 50 s instead of 98 s on 16 GB. Free users see one quiet line after a render with the time Fast draft would have taken on their own Mac.

Free for everyone:
- What's new shows what the update gave you first, then what is new in Pro, all on the first screen.
- A new install notes once where you found Phosphene (our website, Pinokio, or unknown) in the anonymous usage counts. It holds nothing about you; Settings, Anonymous usage analytics turns it off. Details: https://phosphene.video/privacy/?utm_source=github&utm_medium=release&utm_campaign=release-body&utm_content=changelog

Mac app: no new app to download; the app picks up Studio 5.0.33 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
