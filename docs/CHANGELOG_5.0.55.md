# Phosphene 5.0.55

Fixes (Mac app):
- First-time setup in the Mac app now downloads from GitHub and Hugging Face first, with our own server as the backup.
- If setup stops, the Mac app now tells you what to press instead of showing log lines.
- After an update, the Mac app removes old versions it no longer needs, so they stop filling your disk.
- The Mac app's update checks now use almost no data when nothing has changed.

Mac app: it updates itself on its next start. Pinokio: press Update to get the new version number.
