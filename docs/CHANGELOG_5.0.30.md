# Phosphene 5.0.30

Fixes, free for everyone:
- A reference picture you move or delete after attaching it no longer fails the render. Phosphene now keeps its own copy of every picture, clip or sound you attach to a job, so the render finds it even if the original file is gone.
- Songs on smaller Macs wait for memory instead of stopping. When a video has just finished, the song now waits up to five minutes for memory to free up, the same way Hailuo H3 does, instead of failing at the start.
- The picture engine repairs its own install. If its first download was interrupted, Phosphene now retries it once and tries again later on its own; when the disk is full it says so and tells you what to do.

Mac app: no new app to download; the app picks up Studio 5.0.30 on its next update check (or choose Check for Updates). Pinokio: press Update, then restart.
