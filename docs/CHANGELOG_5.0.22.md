# Phosphene 5.0.22

Free for everyone:
- Keeping models on an external drive is easier to find. In the Mac app, the Studio's Settings (under Models) and the Models screen now show "Move to another drive…". With the new Mac app 5.0.22 the button opens the move straight away; on Mac app 5.0.20 and 5.0.21 they say where it is (Phosphene > Settings… in the menu bar, then Models); older Mac apps get a Check for updates button first.

Mac app 5.0.22:
- The Mac app no longer gets stuck on "Opening Phosphene…" when a new Studio download stalls (slow or VPN connections). It opens the Studio you already have and installs the new one in the background; a download that stops sending now fails and retries instead of waiting for ever.
- "Move to another drive…" in the Studio opens the app's Settings at Models.

Pinokio: press Update, then restart. Nothing changes for Pinokio users except this release number.
